# 28 — Functional-Equivalence Rubric (arm-blind)

Each criterion is scored **PASS / FAIL / INDETERMINATE** from the standardised concept description (SCD, 29) alone. Assessors never see arm labels, brief text or the participant's identity. Functional inadequacy is a **separate outcome**. No environmental penalty is attached to concepts rejected before manufacture (18 §2).

| Criterion | TA beverage serving | TB take-away meal | INDETERMINATE when |
|---|---|---|---|
| E1 Required service | Holds and allows drinking of the specified volume, hot and cold | Contains the specified meal (liquid, semi-solid and solid) from kitchen to consumer | The SCD does not state capacity or containment |
| E2 Adequacy | No leakage while carried; stable on a surface | Lid and seal suitable for transport; no leakage for the stated time | The sealing or closure is not described |
| E3 Safety | Safe thermal handling of hot drinks; food-contact-suitable material class | Food-contact-suitable; microwave/heat use stated or excluded | The material class is not specified |
| E4 Hygiene | A cleaning route is defined for reusables (who washes, how) | Same, plus a return-and-sanitise route | Reuse is implied but cleaning is not stated |
| E5 Accessibility | One-handed use; usable with limited grip | Openable with limited grip; carryable | Not described |
| E6 Technical feasibility | Manufacturable with existing processes at the stated mass class | Same | The process is unknown and cannot be mapped to an archetype |
| E7 Service duration | Lasts the drinking time (≥ 30 min hot) | Lasts the delivery and consumption time (≥ 60 min) | Durability is not stated |
| E8 Supporting infrastructure | All required systems named (washing, return, dispenser) | Same (return logistics, washing) | The concept relies on an unnamed system |

**Outcome:** PASS = all criteria pass; FAIL = any criterion fails; otherwise INDETERMINATE. Every criterion-level score is retained. Thresholds (volumes, times) are fixed per task before the pilot.
