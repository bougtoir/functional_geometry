# CTEP novelty gate — STEP 3

Date: 2026-10-18. Evidence base: `CTEP_CLOSEST_PRIOR_STUDIES.csv` (13 DOI/ID-verified studies: Allwood 2011/2013, Liedtke 2014 MIPS, Bovea & Pérez-Belis 2012, Ardente & Mathieux 2014, Bocken 2016, Willskytt 2021, van der Voet 2004, Castro 2022 rebound, Wever 2011 packaging, Chitaka 2020 + Zanghelini 2020 straw LCAs, Yerraju 2026 CTEP packaging review) + `CTEP_CITATION_ECOLOGY.md`.

## Hostile objection under test

> "This merely relabels eco-design, combines elementary break-even equations, and simulates assumed behavior without demonstrating a new method or measured effect."

### Strongest evidence-based response

The verified closest literature establishes that the *objective* (service-denominator material efficiency) and the *individual levers* (lightweighting, rebound, packaging optimization, straw LCAs) are established — but no identified prior study provides:

1. **Explicit pass/fail boundaries** for a proposed geometric reduction before implementation (inverse-ratio break-even, elasticity = −1 boundary, task-mixture expectations for granularity changes, expected-additional-replacement-rate vs independent-failure-probability boundaries, integer packing discontinuities).
2. **A falsification structure**: each modeled benefit is paired with the specific measurement that would falsify it (validated in `manuscript_values.csv` where every number is labeled HYPOTHETICAL_SCENARIO / ANALYTICAL_BOUNDARY / CALCULATED_FROM_PATENT_TABLE).
3. **Three connected consumable cases** exercising the same single framework (width, selectable granularity, accessory–container co-design), which none of the 13 closest papers combine.

That is a method contribution in the (B) class of `CTEP_CITATION_ECOLOGY.md`: original integration producing new structure plus a falsification device — not (A) a new theory, and not (C) an empirical result. The manuscript and cover letter now state exactly this, concede that the underlying concepts pre-exist, and label all scenario outputs as non-empirical.

### Strongest unresolved weakness

The framework's *behavioral parameters are unvalidated*. There is no human-use or industrial trial: width-compensation elasticity, task-mixtures, replacement-rate outcomes, and acceptance are assumed distributions, not measured effects. If a CTEP editor requires demonstrated real-world effect for an "Original research paper," the incremental contribution reduces to equations + simulations of assumed behavior — the desk-rejection critique transfers at reduced but nonzero force. Mitigations in place: explicit staged validation protocol section, scenario labels everywhere, patent table presented as weak evidence, no transport-emission or LCA-aggregate claims.

## Rubric (0–5 scale)

- 0 = absent/contradicted; 1 = marginal; 2 = present but undifferentiated; 3 = defensible incremental contribution; 4 = clear, well-supported advance; 5 = field-level advance.
- Rubric fixed before scoring; threshold for GO = novelty ≥3 AND CTEP fit ≥3. Not tuned post hoc.

| Dimension | Score | Basis |
|---|---|---|
| Novelty vs 13 closest studies | 3 | Defensible incremental contribution (B): integrated boundary/falsification framework absent from verified prior work; every constituent concept is prior art, so not 4 |
| CTEP fit (scope + article type + fee route) | 4 | Official scope includes "mathematical and computer-based methods and models for designing, analyzing, and measuring the cleanliness of products"; Original research paper type accepts modeling papers; subscription route = zero mandatory fees. Not 5: fit relies on the modeling clause rather than the journal's empirical core |

## Verdict

**GO** — publishable incremental contribution (screening + falsification framework for geometric source reduction) with defensible CTEP scope fit and a zero-mandatory-fee subscription route. Residual risk: editor may judge the lack of empirical validation as disqualifying for the article type; this is an editor's call the paper cannot eliminate, only disclose. EDS fallback is therefore not needed now but remains credible if CTEP desk-rejects on validation grounds (its scope more explicitly welcomes methodological modeling papers).

JCLP rejection (insufficient novelty): the retarget does not merely rename FGO — the reframing is a repositioning of the claimed contribution (screening/falsification instrument), which is what the novelty gate actually tests. Claimed concretely in cover letter and abstract.
